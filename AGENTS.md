# Правила работы над проектом

- Приложение разрабатывается как Telegram Mini App.
- Интерфейс и документация ведутся на русском языке.
- Визуальный стиль: темный футуристичный интерфейс с неоновыми акцентами.
- Реальные платежные ключи никогда не добавлять в код.
- Все секреты хранить только в `.env`.
- После каждого крупного этапа запускать приложение и проверять ошибки.
- Не удалять рабочую функциональность без объяснения.
- Перед серьезными архитектурными изменениями фиксировать решение в `DECISIONS.md`.
