# Дизайн-система

## Общий стиль

- Темная тема.
- Неоновые фиолетовые, синие и бирюзовые акценты.
- Футуристичный, но читаемый русский шрифт.
- Интерфейс должен выглядеть технологично, но оставаться удобным для быстрого выбора товара в Telegram.

## Компоненты

- Карточки товаров с эффектом свечения.
- Кнопки с плавными анимациями наведения и нажатия.
- Плавные переходы между состояниями интерфейса.
- Акценты использовать дозированно, чтобы каталог и оформление заказа оставались читаемыми.
