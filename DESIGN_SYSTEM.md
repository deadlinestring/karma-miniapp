# Дизайн-система

## Общий стиль

- Темная тема.
- Неоновые фиолетовые, синие и бирюзовые акценты.
- Футуристичный, но читаемый русский шрифт.
- Интерфейс должен выглядеть технологично, но оставаться удобным для быстрого выбора товара в Telegram.

## Компоненты

- Карточки товаров с эффектом свечения.
- Кнопки с плавными анимациями наведения и нажатия.
- Плавные переходы между состояниями интерфейса.
- Акценты использовать дозированно, чтобы каталог и оформление заказа оставались читаемыми.

## Изображения

- Hero-блок должен иметь крупное изображение ночника или световой панели как часть первого экрана.
- Поверх крупных изображений использовать затемняющий градиент для читаемости текста.
- Карточки товаров проектируются под настоящие фотографии ночников.
- Для обложек товаров использовать единое соотношение сторон, чтобы сетка каталога не прыгала.
- У товара должна быть основная обложка и небольшая галерея дополнительных изображений.
- В mock-режиме можно использовать локальные стилизованные ассеты, но не случайные изображения из интернета.

## Анимации

- На desktop у карточек допускается небольшое увеличение изображения и усиление свечения при наведении.
- На mobile у карточек и кнопок допускается аккуратное уменьшение при нажатии.
- Анимации должны быть сдержанными, плавными и премиальными.
- Не использовать резкие, кислотные или чрезмерно киберпанковые эффекты.
