# KARMA — Telegram магазин ночников

KARMA — будущий Telegram Mini App для магазина кастомных акриловых ночников и настенных световых панелей.

Проект находится на этапе подготовки: сейчас зафиксированы базовые правила, продуктовая спецификация, первые решения, этапы работ и направление визуального стиля. Само приложение, зависимости и реальные платежные интеграции пока не создаются.
